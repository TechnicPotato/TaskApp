# Architecture decision records

Each record explains one significant design decision: the context, what was decided, the trade-offs, and the alternatives that were rejected. Records are numbered in the order they were written and are not rewritten afterwards. If a decision changes, a new record replaces the old one, and the old one is marked as superseded.
